# TSA-Forecasting-Axis-Flexi-Cap-MF-
Forecasted Axis Flexi Cap Fund NAV using Python and time-series analysis. Compared Naive, Moving Average, Holt’s Exponential Smoothing, and ARIMA models, using ADF testing and residual diagnostics. Holt’s model achieved the lowest test MAPE of 2.76% and was used for a 30-trading-day forecast.
